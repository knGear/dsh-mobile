# dsh-mobile

DeepSeek Harness（dsh）的移动端适配仓库，由**插件**与**APK**两部分组成。

## 插件 dsh-mobile-ui

简易移动端 UI 适配：浏览器地址加 `/m` 即可进入移动版，不带 `/m` 体验原版。

**安装**（官方命令）：

```sh
dsh plugin --profile web add github:knGear/dsh-mobile
```

装完重启 `dsh web` 生效。

## APK dsh-mobile

- 本地部署 dsh（未完成）
- 连接 dsh 实例

**下载**：[Releases](https://github.com/knGear/dsh-mobile/releases)
